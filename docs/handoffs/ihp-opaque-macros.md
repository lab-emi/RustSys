# Opaque hard macros and Ibex verification

An SRAM implementation is retained as an original named cell instance, never inferred from an empty interface module. Supplied Liberty `is_macro_cell`/memory metadata identifies opaque cell types. Elaboration creates free output cuts and observed input cuts. Mapping and Boolean rewrites cannot cross these cuts. Emission restores the original macro instances and internal wires. The library must cover the entire original directional pin interface and have a positive finite area. Parameterized macros, inout/complex packed interfaces and electrical optimization are explicitly unsupported. Empty, undriven interface-only children without a matching macro library are errors.

Macro interface expansion uses configurable `SynthOptions::opaque_limits`/`ElabOptions::opaque_limits`, with defaults of 4096 instances and 65536 combined pin bits. The running bit counter avoids rescanning previous instances. Non-zero and ascending bus ranges retain their original Liberty pin names and Verilog bit ordering. Mapping delay/depth only cover the logic between macro boundaries; the diagnostic requires separate macro-aware STA.

## Independent proof method

The Ibex campaign preserves all original RTL text except replacing the two top-level SRAM instances with matching free output inputs and observed input outputs. Every address, mask, BIST, data and clock bit remains in the observed interface. This is valid composition for two identical SRAM instances; no SRAM reset, initialization or guessed behavioral implementation is added. The gate side is transformed by the external Yosys `expose -evert` operation. The existing independent RTL interpreter builds arbitrary-state/event obligations, and the external ABC executable proves all of them.

Do not lower the golden RTL through Yosys and then trust automatically proposed state bindings. Generated `genblk3` path names made 75 names differ in the first attempt, and proposal heuristics paired multiplier numerator registers with multiplier FSM state. ABC correctly rejected the resulting false theorem. Preserving the original RTL uses exact named state correspondence and needs no proposed relations. The failing theorem and counterexample remain in the campaign evidence.

EZ130 TIEHI/TIELO carry contradictory `driver_type` attributes in the original Liberty. For functional proof only, the external tool flattens those two original Liberty constant functions; the original timing library is unchanged. Their vendor Verilog constant behavior must remain validated. Electrical drive strengths and four-state unknown behavior are outside this two-valued Boolean proof.

Evidence is in the root `.work/ibex-sg13g2-repair/synth-agent` directory, not a published benchmark. `proof-original.json` binds the original source, mapped netlist, libraries, tool binaries, 8376 proof obligations and three negative controls (macro address bit, macro return bank, gated-clock bypass). `cts03-proof/` applies the same proof to the corrected clock tree exported by the physical engine. Passing CEC is independent of DRC, LVS and extracted timing; all remain separate required gates.

Resource plan: 2 build/test workers; 4 GiB build/test cgroups; 2 GiB proof cgroups. Native proof preparation uses about 100 MiB and ABC about 26 MiB for this design. The first mismatched-name native SAT attempt reached its 180 s wall cap; it was not a pass. Keep failure artifacts and OS limits.

Latest detailed task state, qualified artifact hashes and pending checks are recorded in `.work/ibex-sg13g2-repair/synth-agent/STATUS.md` at the superproject root. The final storage change retains one port name/range and performs indexed Liberty lookup, avoiding per-bit name duplication. Final rebuilds in all three standard-cell libraries are byte-identical to their previously proved outputs (final-reproduction.json). Whole-workspace testing passed475 tests/6 CUDA ignores, final Clippy passed; cross-frontend X refinement attempts were explicitly stopped unverified (cross-frontend-status.json). Do not treat documentation of earlier passing proofs as a full physical-flow pass.

## Real SRAM device-level LVS lesson

The original IHP macro CDL has independently documented legacy bitcell resistor layer/width errors. Keep the original source and GDS untouched; apply only the hash-pinned metadata overlay. Physical bitcell MOS geometry crosses the leaf boundary, so compare at the verified16x2 tile instead of black-boxing the leaf. Several peripheral PG islands are physically joined by their parents. Original macro labels on metal pin datatype2 must be read; local PG must-connect plus top_level(true) preserves the obligation to close them physically. A real22MOS BLDRV closed/open parent-bridge fixture rejects an unclosed VDD. KLayout ignores TERM in some comparisons: KILL the exact own cgroup after timeout and verify inactivity.

The full selected1P macro now matches45/45 circuits with193 strict top pins and no extraction errors. Width/layer/short controls reject; a deleted redundant M4 strap still matched and is deliberately retained as an ineffective control. Frozen inputs and complete provenance live in macro-lvs-review/qualification.json. Root integration/ibex_sg13g2_ez130/prepare_sram_lvs.py regenerates the exact qualified CDL/deck hashes from the original Apache PDK; it only prepares inputs and does not itself claim an LVS pass. Whole-chip DRC/LVS/timing remain distinct gates.
